# 🧠 Git Personality Profiler

Ontdek wie je echt bent als ontwikkelaar door de lens van je Git-geschiedenis. Ben jij een nachtuil, een perfectionist, of een chaos-aapje?

## 🚀 Hoe te gebruiken

1. Zorg dat je Python 3 hebt geïnstalleerd.
2. Navigeer naar de directory van dit project (of een ander Git project dat je wilt analyseren).
3. Run het script:

```bash
python3 profiler.py [pad-naar-repo]
```

## 📊 Archetypes

- **🧛 The Midnight Hacker**: Commits diep in de nacht.
- **🐦 The Early Bird**: Commits bij het ochtendgloren.
- **✨ The Perfectionist**: Veel refactors en fixes.
- **🐒 The Chaos Monkey**: Korte, vage commit messages (wip, oops, .).
- **📜 The Bard**: Schrijft kleine romans in commit messages.

## 🛠️ Installatie

Geen externe libraries nodig! Gewoon puur Python en Git.
